隐私说明

Short version: no accounts, no tracking, no cookies.

一句话版本

这个网站不收集你的个人数据，不使用 cookie，也没有分析工具。不需要注册，不要求邮箱，不追踪你在站内的行为。

具体说明

  • 账号：本站没有账号系统，不收集姓名、邮箱、电话或任何身份信息。
  • Cookie：本站不设置任何 cookie。
  • 分析工具：目前没有安装 Google Analytics 或任何第三方统计、广告脚本。
  • 浏览器本地存储：声调训练器用浏览器的 localStorage 记住你的最高连对纪录。这个数字只存在你自己的设备上，不会上传，清除浏览器数据就会消失。
  • 托管日志：本站托管在 GitHub Pages。访问日志由 GitHub 按其隐私政策处理，本站无法读取个人级别的访问记录。
  • 外部链接：链接到 GitHub 等外部网站时，那些网站适用它们自己的隐私政策。
  • 儿童：内容面向普通中文学习者，不针对 13 岁以下儿童定向收集任何信息——实际上本站不收集任何人的信息。

如果将来接入广告

如果本站以后接入 Google AdSense 或其他广告服务，会带来两个变化：使用 cookie（用于广告投放与频次控制），以及可能使用第三方统计。在那之前，这一页会先更新，明确写清使用了什么、用途是什么、如何关闭。

目前：没有广告，没有 cookie，没有统计。
