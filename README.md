# 汉语慢慢学：静态课程网站

> 汉语慢慢学 · Hanyu Manman Xue — https://mandarinhappylearning.top

这是一个纯静态、多页面的汉语入门学习网站。目标学习者是英语母语者或熟练英语使用者，内容面向零基础至基础沟通阶段，课程规划目标为约 1,000 个常用词汇。

## 页面结构

- `index.html`：主页与学习路线介绍
- `vocabulary.html`：词汇课程目录和课程搜索
- `grammar.html`：基础语法目录
- `practice.html`：词汇闪电赛、句子拼拼乐、听音找汉字、记忆配对及五种新挑战
- `lesson.html?lesson=greetings`：可复用的课程详情模板；课程数据决定页面内容
- `styles.css`：所有页面共用样式
- `content.js`：词汇和课程内容数据
- `site.js`：目录渲染、课程详情和互动练习逻辑

## 如何添加课程

在 `content.js` 的 `lessons` 数组中复制一条课程对象并修改字段。`slug` 要保持唯一；`type` 用 `vocabulary` 或 `grammar`。目录页和详情模板会自动读取新课程。

词汇课程包含 `words` 字段，每个词依次填写：汉字、拼音、英文释义、中文例句、英文翻译。语法课程包含 `pattern`、`patternEn` 和 `examples`。两种课程都可以配置 `tip` 和 `exercise`。

网站目前包含 204 节课程（其中 100 节语法课）和 500 个基础词条。互动练习页提供 9 种小游戏，涵盖词汇、造句、听辨、量词、情景回应和分类练习；个人最佳成绩保存在当前浏览器。约 1,000 个词是课程建设目标，不代表全部词汇已录入。扩充时建议按主题分批整理，例如问候与自我介绍、数字与时间、餐饮、交通、住宿、购物、健康、校园生活和学习沟通，并由具备汉语教学经验的人校对拼音、语义和例句。

内容应原创编写。教材可用于规划学习顺序和核对知识点，不要直接复制教材课文、图片或音频。

## 本地预览与部署

直接打开 `index.html` 可以预览。也可以把 `outputs` 目录发布到 GitHub Pages、Cloudflare Pages 等静态托管服务；此原型不需要 VPS、数据库或构建步骤。
