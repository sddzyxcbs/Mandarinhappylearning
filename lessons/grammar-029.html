如果……就……

Talk about a possible condition.
8 分钟基础语法日常表达

本课目标 · Lesson goal

理解并能在日常场景中使用“如果……就……”结构。 Talk about a possible condition.

本课学习“如果……就……”。Talk about a possible condition 先观察结构，再用熟悉的生活词汇练习。 This lesson introduces a practical sentence pattern. Read the examples, then try the quick check.

表达结构 · Sentence pattern

如果 + condition，就 + resultTalk about a possible condition

例句 · Examples

  • 如果你有空，我们就见面。If you’re free, we’ll meet.
  • 我每天都学习中文。I study Chinese every day.

学习提示 · Study tip

先记住结构“如果 + condition，就 + result”，再替换其中的时间、人物或地点。注意把新结构和已经学过的词汇一起练习。 First remember the pattern, then replace the time, person, or place with words you already know.

小练习 · Quick check

哪一句最适合练习“如果……就……”？ Choose the best example.

  1. 如果你有空，我们就见面。
  2. If you’re free, we’ll meet.
  3. 我昨天学校。
查看答案 · Show answer

如果你有空，我们就见面。 — 这句话使用了本课的结构：如果 + condition，就 + result。 The example follows this pattern.
