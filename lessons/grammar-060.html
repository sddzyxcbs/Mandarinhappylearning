用「得」说程度

Use 得 to describe how an action is done — run fast, speak well.
10 分钟grammardegree-complement

本课目标 · Lesson goal

掌握「动词 + 得 + 形容词」的程度补语，描述动作做得怎么样。

想说明「动作做得怎么样」时，用「动词 + 得 + 形容词」。比如「他跑得快」，而不是「他跑快」。

表达结构 · Sentence pattern

动词 + 得 + 形容词　/　形容词 + 极了verb + 得 + adjective / adjective + 极了 (extremely)

例句 · Examples

  • 他跑得很快。He runs very fast.
  • 她中文说得很好。She speaks Chinese very well.
  • 今天冷极了。It's extremely cold today.
  • 我累得没力气说话。I'm so tired I have no energy to talk.

学习提示 · Study tip

注意区分：美丽的花（的）、认真地听（地）、听得很认真（得）。「得」后面说结果或程度。

小练习 · Quick check

他___很快。

  1. 跑得
  2. 跑着
  3. 跑在
查看答案 · Show answer

跑得 — 「动词 + 得 + 形容词」描述动作的程度：跑得快。
